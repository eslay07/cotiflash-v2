# Guía visual actual

[Descargar la guía en PDF](Guia_Visual_Actual.pdf). Actualizada el 29 de octubre de 2026.

## Procedencia de la captura

AdminPanel.html del repositorio público, renderizado localmente. Datos sintéticos y llamadas de Apps Script sustituidas por respuestas de demostración; no se conectó a WhatsApp ni Groq.

## Verificación realizada

Se comprobó la representación local del catálogo con tres productos ficticios. La muestra ilustra el panel administrativo; no presenta una cotización ni una conversación externa como ejecutadas.

Las demostraciones no publican credenciales ni datos operativos privados. No se añaden cifras de ahorro ni resultados comerciales sin medición.
